# UI Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add browser-style UI zoom to the Hermes Desktop Electron app: `Ctrl+=` / `Ctrl+-` / `Ctrl+0` and `Shift`+mouse-wheel, scaling the whole UI via `webContents.setZoomLevel`, with the level persisted across restarts (localStorage).

**Architecture:** A pure zoom module (`src/main/zoom.ts`) owns clamping + the controller (apply + broadcast `ui-zoom-changed`). Main intercepts keyboard via `before-input-event` and routes the menu's zoom items through the same controller. Renderer forwards Shift+wheel gestures over IPC (`zoom-by`), restores the persisted level on mount (`zoom-apply`), and persists every broadcast. Three new IPC channels, three new preload bridge methods.

**Tech Stack:** Electron (BrowserWindow/webContents zoomLevel), TypeScript, vitest (jsdom), React (renderer hook), electron-vite + electron-builder.

**Spec:** `docs/superpowers/specs/2026-08-02-ui-zoom-design.md`

**Repo facts:** branch `custom`, remote `fork`. Build portable: `npm run build && npx electron-builder --win portable --x64` → `dist/hermes-desktop-0.7.4-portable.exe`. Tests: `npm test` (= `vitest run`, includes `tests/**/*.test.ts`), typecheck: `npm run typecheck` (= node + web).

```ts
export const ZOOM_MIN = -3.5;
export const ZOOM_MAX = 3.5;
export const ZOOM_STEP = 0.5;

export function clampZoomLevel(level: number): number {
  return Math.min(ZOOM_MAX, Math.max(ZOOM_MIN, level));
}

export function nextZoomLevel(current: number, delta: number): number {
  return clampZoomLevel(current + delta * ZOOM_STEP);
}
```

- [ ] **Step 3: Extend `src/main/zoom.ts`** (append below the pure functions)

```ts
export interface ZoomTarget {
  webContents: {
    getZoomLevel(): number;
    setZoomLevel(level: number): void;
    send(channel: string, level: number): void;
  };
}

function applyAndNotify(target: ZoomTarget, level: number): number {
  const clamped = clampZoomLevel(level);
  target.webContents.setZoomLevel(clamped);
  target.webContents.send("ui-zoom-changed", clamped);
  return clamped;
}

export function zoomBy(target: ZoomTarget, delta: number): number {
  return applyAndNotify(target, nextZoomLevel(target.webContents.getZoomLevel(), delta));
}

export function zoomReset(target: ZoomTarget): number {
  return applyAndNotify(target, 0);
}

export function zoomApply(target: ZoomTarget, level: number): number {
  return applyAndNotify(target, level);
}
```

`BrowserWindow` structurally satisfies `ZoomTarget` (its `webContents` has `getZoomLevel`/`setZoomLevel`/`send`), so no Electron import is needed here — keeps the module testable.

```ts
  // Browser-style UI zoom: Ctrl+= / Ctrl+- / Ctrl+0. preventDefault also
  // suppresses the menu accelerators for the same chords (no double-zoom).
  mainWindow.webContents.on("before-input-event", (event, input) => {
    if (input.type !== "keyDown") return;
    if (!(input.control || input.meta)) return;
    if (input.key === "+" || input.key === "=" || input.code === "NumpadAdd") {
      event.preventDefault();
      zoomBy(mainWindow, 1);
    } else if (
      input.key === "-" ||
      input.code === "NumpadSubtract"
    ) {
      event.preventDefault();
      zoomBy(mainWindow, -1);
    } else if (input.key === "0") {
      event.preventDefault();
      zoomReset(mainWindow);
    }
  });
```

```ts
export const WHEEL_STEP_PIXELS = 100;

export function stepWheelDelta(
  acc: number,
  deltaY: number,
): { steps: number; remaining: number } {
  const total = acc + deltaY;
  const steps = Math.trunc(total / WHEEL_STEP_PIXELS);
  return { steps, remaining: total - steps * WHEEL_STEP_PIXELS };
}
```

- [ ] **Step 1: Write the hook** (`src/renderer/src/hooks/useUiZoom.ts`)

```ts
import { useEffect } from "react";
import { stepWheelDelta } from "./zoomWheel";

const ZOOM_STORAGE_KEY = "hermes.ui.zoomLevel";

export function useUiZoom(): void {
  useEffect(() => {
    const stored = Number(localStorage.getItem(ZOOM_STORAGE_KEY));
    if (Number.isFinite(stored) && stored !== 0) {
      window.hermesAPI.zoomApply(stored).catch(() => undefined);
    }

    const unsubscribe = window.hermesAPI.onUiZoomChanged((level) => {
      localStorage.setItem(ZOOM_STORAGE_KEY, String(level));
    });

    let acc = 0;
    const onWheel = (event: WheelEvent): void => {
      if (!event.shiftKey) return;
      event.preventDefault();
      const { steps, remaining } = stepWheelDelta(acc, event.deltaY);
      acc = remaining;
      if (steps !== 0) {
        window.hermesAPI.zoomBy(steps).catch(() => undefined);
      }
    };
    window.addEventListener("wheel", onWheel, { passive: false });

    return () => {
      unsubscribe();
      window.removeEventListener("wheel", onWheel);
    };
  }, []);
}
```
